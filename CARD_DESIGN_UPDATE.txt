NDC EXCO Membership Portal – Card Design Update

This package uses the uploaded reference design as the visual direction for the portal's dynamic ID card.

Card size
- Standard CR80 ID card: 85.60 mm × 53.98 mm
- Landscape orientation
- Front and back print as separate CR80 pages at 100% / Actual Size

Front
- NDC logo and Nigeria Democratic Congress header
- Service to the People tagline
- EXCO Membership Card title ribbon
- Member passport photograph
- Membership number
- Full name
- Position
- EXCO level
- Gender
- State
- LGA (hidden for State EXCO)
- Ward (shown only for Ward EXCO)
- Polling unit code (shown only for Ward EXCO)
- Member signature
- Authorized signature
- National Chairman authorization line

Back
- Simplified to essential information only
- NDC branding
- QR code and Scan to Verify
- Membership number
- Short authentication text
- Ownership / return instruction
- Current-office notice (no expiry date)
- No unnecessary phone number, email, website, headquarters graphic or expiry date

The portal functionality, Firebase data model, Ward/LGA/State registration, NIN flow, admin approval and replacement logic are retained.
