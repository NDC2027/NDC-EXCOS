NDC EXCO WEBSITE - VS CODE + GITHUB PAGES

1. Extract this ZIP and open the folder in Visual Studio Code.
2. Open firebase-config.js and paste your Firebase Web App configuration.
3. In Firebase Authentication enable Anonymous and Email/Password.
4. In Firestore create the database and publish the contents of firestore.rules.
5. Create your admin Email/Password user. Copy its UID and create admins/{UID} with active=true.
6. Install VS Code Live Server, right-click index.html, choose Open with Live Server, and test registration/admin/verification.
7. Create a GitHub repository and push ALL files in this folder.
8. GitHub repository -> Settings -> Pages -> Deploy from a branch -> main -> /(root).
9. In Firebase Authentication -> Settings -> Authorized domains, add your GitHub Pages hostname if needed.
10. For live NIN retrieval later, set NIN_VERIFY_ENDPOINT in firebase-config.js to your approved secure backend URL.
